# Оборона ЦОД Сбербанк от БПЛА (2.5D Pixel Mini-Game)

Тактическая 2.5D мини-игра на чистом JavaScript (HTML5 Canvas + Web Audio API) с приятной пиксельной графикой и современным тактическим интерфейсом (Modern UI).

---

## 🎯 Сюжет и задача
Вы — командир расчета Мобильной Оперативной Группы (МОГ). Ваша задача — охранять ключевой **Центр обработки данных (ЦОД) Сбербанка** от массированных атак ударных и разведывательных БПЛА противника. 

В первом уровне вам предстоит отразить **5 волн беспилотников**, после чего перехватить мини-босса — **баллистическую ракету «ФЛАМИНГО»**.

---

## 🎮 Управление
| Клавиша / Кнопка | Действие |
| :--- | :--- |
| **`W` `A` `S` `D`** | Управление движением боевой машины МОГ по периметру (с глубиной 2.5D) |
| **`Мышь`** | Наведение поворотной турели ПВО на воздушные цели |
| **`ЛКМ` (Левая кнопка мыши)** | Огонь из текущего оружия (автоматический огонь для пулемета, запуск для ракет) |
| **`ПКМ` (Правая кнопка мыши)** | **Тактический прицел / Зум** (приближение 1.6x, оптическая сетка, дальномер) |
| **`1` / `2`** | Выбор оружия: `[1]` Тяжелый пулемет, `[2]` УР «Вихрь-1» |
| **`Q`** или **`Колесо мыши`** | Быстрое переключение между оружием |
| **`R`** | Тактическая перезарядка пулемета |
| **`ESC` / `P`** | Тактическая пауза |

---

## ⚔️ Вооружение машины МОГ
1. **Тяжелый пулемет (ТКП-12.7 мм)**:
   - Кассета на **150 патронов**.
   - **Бесконечный боезапас** (каждая перезарядка восполняет 150 патронов).
   - Высокая скорострельность, яркие трассирующие пули, вылет гильз.
   - Автоматическая перезарядка при опустошении или по нажатию `R`.
2. **Управляемые ракеты «Вихрь-1»**:
   - Начальный боекомплект: **5 ракет**.
   - **Управляемый полет**: ракета в реальном времени следует за лазерным курсором мыши до цели!
   - Мощный урон по площади (осколочный взрыв уничтожает скопления дронов).
   - **Восстановление**: **+1 ракета каждые 30 секунд** (до максимума 5 ракет).

## 🛸 Враги и механика волн
- **Волны 1–5**: В небе появляются различные типы БПЛА:
  - *Камикадзе «Крыло»* (треугольное стреловидное крыло, высокая скорость)
  - *Разведчик «Око»* (верткий гексакоптер с маневрированием)
  - *Тяжелый ударный БПЛА «Альбатрос»* (двухбалочный бомбардировщик повышенной прочности)
  - *Микро-рои «Шершень»*
  - **Когда летят БПЛА — тревоги нет.**
- **Мини-босс: Баллистическая ракета «ФЛАМИНГО»**:
  - Запускается после отражения 5-й волны!
  - **Военная воздушная тревога**: в динамиках начинает звучать реалистичная воющая сирена ПВО.
  - Повышенная прочность (**х2 урон для уничтожения**).
  - Оставляет огромный дымовой и огненный шлейф.
  - При уничтожении «Фламинго» засчитывается **полная победа**!

---

## 🎨 Графика и технологии
- **Чистый WebJS**: Никаких внешних библиотек или сборщиков, 100% нативный HTML5 Canvas.
- **Web Audio API**: Все звуки (выстрелы пулемета, запуск ракет, взрывы, лязг затвора, мотор, военная сирена) синтезируются процедурно в реальном времени.
- **Пиксельная графика 2.5D**: Процедурные спрайты высокого качества (комплекс ЦОД Сбербанка с серверами и логотипом, боевая машина МОГ, турель, ракеты, частицы взрывов, облака).
- **Modern UI**: Стеклянный полупрозрачный тактический интерфейс (Glassmorphism), мини-радар дальнего обнаружения, индикаторы боезапаса, предупреждающие баннеры.

---

## 🚀 Запуск
Просто откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari, Яндекс.Браузер). Игра работает как локально (двойной клик по файлу `file:///...`), так и через любой веб-сервер.
